# PLT-11 Research Bundle v2 (2026-10-23)

Start with `PLT11_research_handoff.md` for aerial and pump data, then read `PLT11_chassis_engine_addendum.md` for newly documented chassis/engine data.

**Important newly found ambiguity:** A chassis plate showing 736 cu in, 4.84 × 5.0 in and eight cylinders matches the Detroit 8V92 geometry, but its engine serial appears to start `08VA` (8V71-style prefix), not `08VF` (8V92). Do not assert exact installed engine model until block serial verification.

Original photographs are under `photos/` and `photos/chassis/`. Structured data are under `data/`.

Do not apply old chassis fluid recommendations directly to present-day servicing without validating current installed components and OEM revisions.
